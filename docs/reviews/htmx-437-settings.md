## Action inventory

All ordinary forms and links below use browser navigation, not HTMX swaps, history pushes, `hx-sync`, or HTMX timeouts. Pending means the browser's ordinary request; no dedicated HTMX pending state exists. Native history and ordinary forms remain the no-JavaScript fallback. No scoped action uses `hx-delete`. Do not cache, preload, or put secrets into drafts or history. Unless explicitly adopted below, defer HTMX for each action: its benefit does not justify the additional state and failure handling. Decisions are review recommendations for the named implementation issues, not permission to change behavior in this review.

## Cross-cutting HTMX 4 decisions

The pinned vendored build is 4.0.1 ([capability evidence at the reviewed commit](https://github.com/dynamiscode/dynamis-code-apps-template/blob/81c496187ec060f359a38e844859c23c5e265931/docs/capabilities.md#htmx-4-upgrade-evidence)). [Upstream 4.0.1 changes](https://github.com/bigskysoftware/htmx/blob/v4.0.1/www/src/content/docs/whats-new-in-htmx-4.md) document explicit inheritance, DELETE input exclusion, no history cache, 60-second default timeout, response swapping and synchronization. Current `app.js` sets `noSwap=[204,304,"4xx","5xx"]`; do not assume a 422 validation fragment will swap. A future targeted validation needs an explicit compatible status policy and safe 403/5xx handling, tested with the global configuration. Avoid inherited selectors and `hx-delete`; any future DELETE must explicitly include CSRF and other required inputs. Native POST forms already carry them.

Defer request synchronization, timeout overrides, preload, morphing, SSE and hx-live for these actions: no measured need outweighs dirty-input, sensitive-data, duplicate mutation or fallback risks. A timeout or aborted request does not prove a server mutation failed. Do not cache sensitive responses even though HTMX 4 no longer stores history snapshots in localStorage. If a future issue adopts an extension, pin and self-host a compatible version and verify its behavior against HTMX 4.0.1; compatibility of each extension is unverified here. Preserve focus, accessible status/error announcements, responsive layout, English/Spanish, themes, keyboard access and ordinary navigation in each migration.

Context7 indexed HTMX 4.0.0, not 4.0.1; its targeted results were cross-checked against the versioned upstream 4.0.1 source above. No extension compatibility is inferred from 4.0.0 documentation.
