# Standards Exceptions

An exception is required before violating a normative standard. Security
exceptions require approval from the repository security owner.

File name: `YYYY-MM-DD-short-requirement.md`.

```md
# Exception: requirement

- Profile and requirement:
- Status: proposed | accepted | expired | removed
- Responsible owner:
- Approving maintainer:
- Security-owner approval, when required:
- Created: YYYY-MM-DD
- Review by: YYYY-MM-DD
- Expires: YYYY-MM-DD

## Reason and evidence

## User, security, compatibility, and operational risk

## Compensating controls

## Replacement or removal path

## Verification
```

Temporary exceptions must be reviewed within 90 days. An expired exception is
non-conforming. Permanent architecture changes belong in an accepted decision
and the final architecture documentation.
