# Dynamis Code Apps Template

Status: preparation only. This repository does not contain a runnable
application yet.

The repository is preparing a reusable Go web-application template with a
small default footprint and explicit paths to larger deployments. The
temporary [generation standard](STANDARDS.md) is authoritative until the
template passes its final conformance gate.

## Start here

- Maintainers and coding agents: read [AGENTS.md](AGENTS.md), then
  [PLAN.md](PLAN.md).
- Find task-specific context through [docs/README.md](docs/README.md).
- Track planned and deferred capabilities in
  [docs/capabilities.md](docs/capabilities.md).
- Review accepted technology choices in
  [docs/decisions/0001-go-modular-monolith.md](docs/decisions/0001-go-modular-monolith.md).

No build, run, or deployment command is available yet. Phase 07 replaces this
preparation README with the verified application quick start.
