# Code of Conduct

## Our standard

Project participants are expected to:

- be respectful, constructive, and inclusive;
- discuss code and decisions without attacking people;
- welcome different backgrounds and viewpoints;
- respect privacy and avoid publishing personal information; and
- follow the repository's security and contribution rules.

Harassment, discrimination, threats, sexualized conduct, doxxing, deliberate
disruption, and public disclosure of private security details are not
acceptable.

## Scope and enforcement

This policy applies in repository issues, pull requests, reviews, discussions,
project communication, and other spaces when someone is representing the
project. Maintainers may edit or remove content, close discussions, restrict
participation, or remove access in response to violations. Serious or repeated
violations may result in a permanent ban.

## Reporting

Report conduct concerns privately to the repository maintainers through the
contact method configured in the repository profile. Do not open a public
issue with sensitive details. Security vulnerabilities must follow
[SECURITY.md](SECURITY.md).

Reports are handled confidentially as far as practical. Maintainers should
acknowledge a report, investigate it fairly, protect reporter privacy, and
document enforcement decisions without exposing sensitive details.
