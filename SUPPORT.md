# Support

Use this guide for setup, operation, documentation, and reproducible bug
questions. This project does not promise a response time or a support
contract.

## Before opening an issue

- Read [README.md](README.md), [CONTRIBUTING.md](CONTRIBUTING.md), and the
  relevant documentation under [`docs/`](docs/README.md).
- Search the [issue tracker](https://github.com/dynamiscode/dynamis-code-apps-template/issues)
  for an existing report.
- Include the application or template version, Go version, operating system,
  deployment mode, exact safe error, and the smallest reproduction.
- Remove credentials, authorization headers, session or invitation values,
  connection strings, backups, personal data, and signed URLs from reports.

## Triage

- Setup, configuration, operation, and reproducible bugs: open a [bug
  report](https://github.com/dynamiscode/dynamis-code-apps-template/issues/new?template=bug_report.yml).
- Missing or unclear guidance: open a [documentation
  issue](https://github.com/dynamiscode/dynamis-code-apps-template/issues/new?template=documentation.yml).
- Proposed behavior changes: open a [feature
  request](https://github.com/dynamiscode/dynamis-code-apps-template/issues/new?template=feature_request.yml).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md) and use the
  [private reporting channel](https://github.com/dynamiscode/dynamis-code-apps-template/security/advisories/new).
  Do not disclose exploit details in a public issue.

Generated applications inherit this guidance but own their product behavior,
deployment, support expectations, and maintainer response.
